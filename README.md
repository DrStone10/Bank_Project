# Bank Project

## What i did in this project

* The Bank had a `large raw csv file` that holds some info about:
        Clients, Campaign, Economics... Etc

### The objective:
        1. Convert the data into large table.
        2. Split the table into 3 tables by creating a relational model
        3. Cleaning the tables, and this part includes:
           => Renaming columns, Adding new ones, Changing data types ..Etc
        4. Saving the tables as csv files.
        5. Creating the database using the previous model.
        6. Inserting all the data into the database tables.
        7. Final cleaning and checking using SQL.

## Skills needed:

* `python`: pandas, numpy, and some SQL libraries.
* Documentation, Communication and write Clean & Readable code for 
other developers for later use.

#### strong understanding of these concepts:
   * `Data manipilation & cleaning with Python`.
   * `Data manipilation & cleaning with SQL`.
   * Relational Databases and how they work.
